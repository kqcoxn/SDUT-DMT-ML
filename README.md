### 参与开源

#### 基础

在参与贡献前，您应该有基础的 Github 开源常识，可以参考：[【Bilibili】git、github 保姆级教程入门，工作和协作必备技术，github 提交 pr - pull request](https://www.bilibili.com/video/BV1s3411g7PS)

本项目使用 [vitepress](https://vitepress.dev/zh/guide/getting-started) 构建，您无需任何前端基础，只需要了解 [markdown 语法](https://blog.csdn.net/2301_77429467/article/details/147642306)，并知道如何[使用 Node.js 构建本地开发环境](https://blog.csdn.net/m0_57532432/article/details/135964436)。

#### 开发

1. 拉取仓库至本地

```shell
git clone https://github.com/kqcoxn/SDUT-DMT-ML
```

2. 安装依赖

```shell
cd ./SDUT-DMT-ML
yarn
```

3. 开发项目

```shell
yarn dev
```

4. 打包或上传

```shell
yarn build
git add .
# ...
```
